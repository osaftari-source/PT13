# PortOS — OS v13.0.5.6.9
## Mobile Month-Header Typography Fix

Narrow presentation-only public-PWA correction based on PortOS OS v13.0.5.6.8.

### Fixed
- Monthly and Portfolio mobile global header titles no longer inherit the older compact `12px` title rule created for headers containing a month selector.
- Mobile page titles now use the same stronger visual scale as Dashboard and Settings while retaining the existing month selector and header controls.

### Preserved
- Sticky month selector behaviour.
- Dashboard and Portfolio KPI refinements.
- Grid / Calendar / Wallet / Sliders navigation icon family.
- Dark-mode fixes, Recent Transaction notes and number-format fixes.
- App Installation & Update Management.
- Financial calculations, workflow, Apps Script and Google Sheet structure.

### Deployment
No Apps Script, Google Sheet, manifest or icon update is required.
